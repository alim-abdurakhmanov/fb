Аннотация
Настоящий документ содержит информацию, необходимую для установки и начала работы с ПО «FinBuild».
Системные требования
ПО «FinBuild» является клиент-серверным веб-приложением и предоставляется пользователю в виде интернет-сервиса (SaaS). Установка клиентского приложения на устройство пользователя не требуется. Для работы достаточно современного веб-браузера и доступа к сети Интернет.
Минимальные требования к устройству пользователя:
оперативная память: не менее 2 Гб;
процессор: x86_64 / совместимая архитектура (ПК) либо современный мобильный процессор;
операционная система: Microsoft Windows, macOS или иной дистрибутив, поддерживающий работу актуальных браузеров;
доступ к сети Интернет.
Для использования ПО необходим браузер. Поддерживаемыми считаются нижеперечисленные браузеры, начиная с актуальных стабильных версий и по последнюю:
Google Chrome;
Яндекс Браузер;
Mozilla Firefox;
Opera;
Microsoft Edge;
Safari.
Серверная часть ПО разворачивается и сопровождается правообладателем (оператором сервиса). Пользователю не требуется самостоятельно устанавливать серверные компоненты (веб-сервер, СУБД, интерпретатор PHP и др.).
Процесс установки ПО
ПО «FinBuild» относится к клиент-серверному программному обеспечению с доступом через браузер. Отдельная установка дистрибутива на компьютер или мобильное устройство пользователя не выполняется.
Для начала работы пользователю необходимо:
1. Перейти на сайт https://finbuild.ru в поддерживаемом браузере.
2. При отсутствии учётной записи пройти регистрацию (для ролей «Клиент» или «Партнёр») либо получить доступ от оператора сервиса (для сотрудников платформы, банка и иных ролей).
3. Выполнить вход в личный кабинет, указав адрес электронной почты (логин) и пароль.
4. После успешной авторизации открывается личный кабинет в соответствии с ролью пользователя.
Мобильное приложение в магазинах Google Play / App Store для работы с ПО не используется. Доступ осуществляется через браузер.
Начало работы с ПО
После входа в личный кабинет пользователь получает доступ к разделам интерфейса, доступным его роли, в том числе:
к списку и карточкам заявок;
к документам и переписке в рамках доступных заявок;
к инструментам подбора продуктов и аналитики (при наличии прав);
к личному кабинету банка — для пользователей с ролью «Банк»;
к разделам администрирования — для уполномоченных сотрудников платформы.
Подробное описание функций и сценариев работы приведено в документе «Описание функциональных характеристик ПО «FinBuild»».
Процесс завершения работы ПО
Для завершения работы с ПО пользователю необходимо выполнить выход из учётной записи (при наличии соответствующей команды в интерфейсе) и/или закрыть вкладку (окно) браузера с сайтом сервиса.
Отдельная процедура удаления клиентского приложения не требуется, поскольку клиентское приложение на устройство пользователя не устанавливается.
