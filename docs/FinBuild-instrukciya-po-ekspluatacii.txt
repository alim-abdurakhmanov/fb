Общие сведения
Данный документ является руководством по эксплуатации программного обеспечения «FinBuild» (далее – ПО).
Все исключительные права на ПО принадлежат ООО «________».
ПО имеет пользовательский графический интерфейс и доступно по ссылке https://finbuild.ru.
ПО разработано с целью организации полного цикла работы с заявками на банковские гарантии и иные финансовые продукты для бизнеса в едином цифровом контуре: от создания заявки и документооборота до взаимодействия с банками и контроля статусов.
Описание и назначение ПО
ПО «FinBuild» – клиент-серверное веб-приложение (программа для ЭВМ), предназначенное для совместной работы клиентов, партнёров, сотрудников платформы, заказчиков и представителей банков при оформлении и сопровождении финансовых заявок.
ПО позволяет осуществлять:
регистрацию и авторизацию пользователей;
создание и ведение заявок на банковские гарантии и кредитные продукты;
подбор банковских продуктов и предварительный расчёт лимитов;
загрузку, просмотр и выгрузку документов;
коммуникацию участников процесса в чатах;
отправку пакета документов в банк и сопровождение рассмотрения;
работу представителей банка в отдельном личном кабинете;
проведение банковской оценки кредитоспособности;
получение аналитики по компании;
администрирование пользователей, прав доступа и каталога продуктов;
обращение в службу поддержки.
Процесс запуска ПО
Для запуска ПО пользователю необходимо открыть поддерживаемый браузер и перейти по адресу https://finbuild.ru.
Далее пользователь выполняет вход в личный кабинет, указывая адрес электронной почты (логин) и пароль. При отсутствии учётной записи пользователь проходит регистрацию (для доступных ролей саморегистрации) либо получает доступ от оператора сервиса.
После успешной авторизации открывается интерфейс личного кабинета в соответствии с ролью пользователя.
Уровень подготовки пользователей
Пользователям не нужно проходить специальную дополнительную подготовку для работы с ПО.
Пользователи ПО должны обладать следующими минимальными навыками:
уверенная работа с персональным компьютером или иным устройством, имеющим доступ в сеть Интернет;
навыки работы с веб-браузером;
умение пользоваться электронной почтой;
базовые навыки работы с электронными документами (просмотр и загрузка файлов).
Основные компоненты ПО
Ниже описаны основные экраны (окна) пользовательского интерфейса ПО и их назначение.
Страница входа (авторизация)
Данное окно доступно по адресу сервиса до входа в систему. Здесь пользователь проходит авторизацию для доступа к личному кабинету.
Что отображается:
поля для ввода адреса электронной почты и пароля;
кнопка входа в систему;
ссылка на регистрацию (при наличии).
Рекомендации по использованию:
проверяйте корректность ввода логина и пароля;
при утрате доступа обратитесь в техническую поддержку.
Страница регистрации
На данное окно пользователь попадает при выборе регистрации. Здесь он может создать учётную запись для доступа к аккаунту.
Что отображается:
выбор типа учётной записи;
поля для ввода регистрационных данных;
кнопка подтверждения регистрации.
Рекомендации по использованию:
заполняйте данные внимательно и без ошибок;
после регистрации выполните вход в личный кабинет.
Главная страница личного кабинета
Отображается после успешного входа. Служит для быстрого перехода к основным разделам и просмотра сводной информации.
Что отображается:
навигационное меню разделов;
сводка по заявкам и статусам (в пределах прав пользователя);
быстрые действия (например, переход к заявкам или созданию заявки).
Рекомендации по использованию:
используйте меню для перехода между разделами;
состав пунктов меню зависит от роли пользователя.
Список заявок
Раздел предназначен для просмотра заявок, доступных пользователю, и перехода в карточку выбранной заявки.
Что отображается:
перечень заявок со статусами;
средства поиска и фильтрации;
элементы перехода к созданию заявки (при наличии прав).
Рекомендации по использованию:
используйте фильтры для быстрого поиска нужной заявки;
открывайте карточку заявки для детальной работы.
Карточка заявки
Основной рабочий экран сопровождения заявки. Содержит вкладки со сведениями, продуктами, документами, аналитикой, структурой, дорожной картой, методикой (при наличии прав) и чатами.
Что отображается:
основные сведения о заявке и её статусе;
вкладки разделов карточки;
элементы управления в рамках доступных прав.
Рекомендации по использованию:
переключайтесь между вкладками последовательно по мере обработки заявки;
загружайте документы в соответствующие разделы;
используйте чат для коммуникации с участниками процесса.
Раздел продуктов заявки
Предназначен для просмотра и ведения банковских продуктов, подобранных по заявке.
Что отображается:
список продуктов и их статусы;
элементы добавления и открытия карточки продукта (при наличии прав).
Рекомендации по использованию:
контролируйте актуальный статус каждого продукта;
для детальной работы открывайте карточку конкретного продукта.
Карточка продукта / работа с банком
Экран сопровождения конкретного банковского продукта: документы, переписка и отправка пакета в банк.
Что отображается:
сведения о продукте и статусе;
раздел документов и запросов документов;
чат по продукту;
блок работы с банком (формирование и отправка пакета, история статусов).
Рекомендации по использованию:
перед отправкой в банк убедитесь в комплектности документов;
отслеживайте ответы и статусы после передачи пакета.
Личный кабинет банка
Отдельный интерфейс для пользователей с ролью «Банк». Предназначен для рассмотрения поступивших заявок.
Что отображается:
список заявок банка;
карточка заявки с доступными вкладками (сведения, документы, аналитика, структура, методика — при наличии настройки);
элементы смены статуса и чат с менеджером.
Рекомендации по использованию:
работайте только с заявками своего банковского кабинета;
фиксируйте статусы рассмотрения и при необходимости оставляйте комментарии.
Банковская методика
Раздел оценки кредитоспособности принципала. Доступен пользователям с соответствующими правами и/или настройками портала банка.
Что отображается:
блоки заполнения оценки;
результаты расчёта;
элементы сохранения черновика и фиксации версии.
Рекомендации по использованию:
заполняйте разделы последовательно;
перед фиксацией версии проверьте полноту данных.
Аналитика по компании
Инструмент просмотра результатов анализа организации по идентификатору.
Что отображается:
поле ввода идентификатора организации;
результаты анализа;
история запросов (при наличии).
Рекомендации по использованию:
проверяйте корректность введённого идентификатора;
используйте результаты как вспомогательную информацию при работе с заявкой.
Подбор продуктов и расчёт лимитов
Инструменты предварительного подбора банковских программ и расчёта лимитов.
Что отображается:
поля параметров подбора/расчёта;
результаты подбора или расчёта;
элементы запуска расчёта.
Рекомендации по использованию:
задавайте параметры в соответствии с условиями заявки;
результат носит справочный характер для дальнейшей работы.
Личный кабинет (профиль пользователя)
Раздел управления сведениями учётной записи.
Что отображается:
поля профиля;
параметры уведомлений;
элементы смены пароля и сохранения изменений.
Рекомендации по использованию:
поддерживайте актуальные контактные данные;
при смене пароля используйте устойчивую комбинацию.
Поддержка
Раздел для создания обращений в техническую поддержку и ведения переписки по ним.
Что отображается:
список обращений;
форма создания обращения;
история переписки.
Рекомендации по использованию:
формулируйте тему и описание обращения понятно;
при необходимости прикладывайте файлы.
Разделы администрирования
Доступны уполномоченным сотрудникам платформы. Включают управление пользователями, правами доступа, каталогом продуктов и статистикой.
Что отображается:
списки и карточки объектов администрирования;
формы создания и редактирования;
элементы сохранения настроек.
Рекомендации по использованию:
изменяйте права и роли осознанно;
после изменений проверьте доступ соответствующих пользователей.
Выполнение основной задачи
Основная задача ПО — сопровождение заявки на банковскую гарантию (либо иной финансовый продукт) от создания до результата рассмотрения. Типовая последовательность действий пользователя выглядит следующим образом: пользователь создаёт заявку и заполняет её параметры; затем загружает необходимые документы и при необходимости использует инструменты подбора продуктов и аналитики. Сотрудник платформы проверяет заявку, ведёт продукты, запрашивает недостающие документы и при готовности направляет пакет в банк. Представитель банка в личном кабинете банка просматривает материалы, ведёт переписку, при необходимости заполняет оценку и устанавливает статус рассмотрения. Участники процесса контролируют статусы и продолжают работу в карточке заявки до завершения цикла.
Подробные сценарии по ролям приведены в документе «Описание функциональных характеристик ПО «FinBuild»».
Процесс завершения работы ПО
Для завершения работы с ПО пользователю необходимо выполнить выход из учётной записи (при наличии соответствующей команды в интерфейсе) и/или закрыть вкладку (окно) браузера с сайтом сервиса.
